# KeyBoard Shortcuts ScreenSaver
KeyBoard Shortcuts ScreenSaver: a screensaver that shows keyboard shortcuts and their description



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Shows a random keyboard shortcut and its description every 3 seconds, moving on the screen
* Categories: Windows, Excel, Word, Browser (choose them in Settings)
* Multi-Monitor support (covers all monitors)
* Settings saved in the registry
* `Install.bat` / `Config.bat` helpers, and a `.reg` file to restore the `.scr` file association
* Native Windows app (Lazarus / Free Pascal): no runtime needed
